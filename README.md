# 打倒胖胖怪！🍩

用 4 張 NTAG213 NFC 貼紙＋手機鏡頭玩的居家運動 AR 遊戲。iPhone 和 Android 都能玩，是純網頁，**不用安裝 App**。

## 怎麼玩

1. 走到胖胖窩，用**手機上緣**碰一下貼紙
   - iPhone 會跳出通知 → 點通知
   - Android 會直接打開 Chrome
2. **拿著手機**看 AR 胖胖怪登場
3. **把手機放下來**（直立靠牆，全身入鏡），用運動讓牠消風，語音會幫你報數
4. **拿起手機**，點一下精靈收服牠，拿到元氣值 ⚡
5. 收服 4 隻之後，挑戰 **胖胖大王**：限時 2 分鐘內，依序跑去 4 個窩感應，最後再做波比跳

每個窩有兩招，**每天輪流換**：

| 胖胖窩 | 胖胖怪 | 招式 A | 招式 B（肌耐力撐住） |
|---|---|---|---|
| 🍟 薯片窩 | 薯薯胖 | 深蹲 | 深蹲停留 |
| 🧋 奶茶窩 | 珍珠胖 | 開合跳 | 側平舉撐住 |
| 🍩 甜甜圈窩 | 圈圈胖 | 高抬腿 | 單腳平衡（過一半換腳） |
| 🛋️ 懶骨頭窩 | 躺躺胖 | 棒式（側拍） | 臀橋（側拍） |
| 👑 大王 | 胖胖大王 | 波比跳 | |

**漸進式訓練**：同一種運動每完成 2 次就升一級，目標跟著變多（例如棒式 20 秒 → 25 → 30 … 最多 90 秒）。主畫面「💪 訓練」可以看每種運動的等級和下一級目標。

**每日任務**：每天換 3 個任務（例如「肌耐力：累積撐住 90 秒」「去 3 個不同的窩打怪」「完美姿勢：打完一場都沒被提醒」），全部完成再送寶箱。

**獎勵規則**
- 每次讓胖胖怪消風 +50 元氣值，可以重複打
- 每天會有一隻胖胖怪「變胖」，當天第一次打倒牠拿**雙倍**
- 每日任務各 +40～100，三個全完成寶箱 +100
- 打倒大王 +300 元氣值

起始目標、每級增加量、上限、獎勵、貼紙密碼都在 [js/config.js](js/config.js) 調整；每日任務的種類在 [js/daily.js](js/daily.js)。

## 一、架設網站（必須是 HTTPS）

手機的相機權限只有在 HTTPS 網站才能用，所以要把遊戲放上網路。最簡單的兩種方式：

**GitHub Pages（免費）**
1. 在 GitHub 建一個新 repo，把這個資料夾的所有檔案上傳
2. 到 repo 的 Settings → Pages → Branch 選 `main`，資料夾選 `/ (root)` → Save
3. 等 1 分鐘，網址會是 `https://你的帳號.github.io/repo名稱/`

**Netlify Drop（更快，不用帳號設定）**
1. 打開 https://app.netlify.com/drop
2. 把整個資料夾拖進去，馬上就會拿到一個 HTTPS 網址

## 二、寫入 NFC 貼紙

1. 用手機打開遊戲網址 → 完成開場 → 主畫面「⚙️ 設定」
2. 最下面的「🏷️ 貼紙要寫入的網址」會列出 4 個網址，網址會依照你的網站位置自動產生
3. 手機安裝免費 App **NFC Tools**（iPhone / Android 都有）
4. NFC Tools →「寫」→「新增記錄」→「網址/URI」→ 貼上網址 →「寫入」→ 碰貼紙
5. 4 張貼紙都寫完後，建議用「其他」→「鎖定標籤」設成唯讀，避免被覆蓋
   - ⚠️ 鎖定之後就**永遠不能改**了，確定網址正確再鎖

網址長這樣：`https://…/?n=tea&k=m4q9`，`n` 是哪一個窩，`k` 是密碼，避免有人自己在網址列打字作弊。

## 三、貼貼紙

- 4 個窩盡量**分散**，最好在家裡的對角或跨樓層，Boss 戰才有得跑
- **不要貼在金屬表面**（冰箱、鐵門），NTAG213 會讀不到
- 每個窩旁邊最好有地方立手機（牆邊、書櫃、椅腳）
- 遊戲裡只會顯示窩的名字（例如「奶茶窩」），不寫實際地點，換場地玩也不用改設定

## 手機注意事項

| | iPhone | Android |
|---|---|---|
| 支援機型 | iPhone XS 以後（背景感應 NFC） | 有 NFC 的手機，打開 NFC |
| 瀏覽器 | Safari（碰貼紙一定會用 Safari 開，進度存在 Safari 裡） | Chrome |
| 遊戲內感應 | 不支援，每次碰貼紙都會開新分頁，進度會自動接續 | 主畫面按「📡 開啟遊戲內感應」，之後直接碰貼紙，不用換頁 |
| 相機權限 | 可能每次都會問。可以到 設定 → Safari → 相機 →「允許」 | 允許一次就會記住 |

## 本機測試

```bash
python3 -m http.server 8000
```

在電腦瀏覽器開 `http://localhost:8000/?debug=1`：
- 主畫面點胖胖窩 = 模擬感應貼紙
- 戰鬥畫面右側有「模擬 +1」「跳過擺位」按鈕
- 電腦有視訊鏡頭的話，也能真的測試動作偵測

```
js/store.js       進度存檔
```
